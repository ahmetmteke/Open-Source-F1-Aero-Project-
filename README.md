# Open-Source F1 Aero Project
A comprehensive R&D repository focused on Formula 1 aerodynamics, featuring CAD designs, CFD simulations, and performance optimization studies.

🏁About the Project 
   This project is a personal engineering initiative dedicated to mastering the complexities of Formula 1 aerodynamics. As a Mechanical Engineering student with a passion for motorsport, I am using this repository to   document my journey from fundamental fluid dynamics to advanced Computational Fluid Dynamics (CFD) analysis.
   In the absence of a Formula SAE team at my university, I use "Virtual Lab" as my primary platform for designing, testing, and optimizing high-performance racing components.

🏁Core Objectives:
    Component Design: Creating high-fidelity 3D models of F1 wings, floors, and diffusers using Class-A surfacing (SolidWorks/NX).
    CFD Simulations: Conducting steady and unsteady flow analyses to understand air behavior and pressure distributions.
    Optimization: Improving L/D (Lift-to-Drag) ratios and managing "dirty air" (wake) using iterative design processes.
    Data Driven: Validating theoretical calculations with numerical results.

🏁Technical Stack:
    CAD: Solid Works / Siemens NX
    CFD: OpenFOAM / ANSYS Fluent (Mostly ANSYS)
    Post-Processing: ParaView / Python (Matplotlib & NumPy)


🏁Roadmap
    [ ] Phase 1: Single-element airfoil simulation and validation (NACA profiles).
    [ ] Phase 2: Multi-element front wing assembly & ground effect study.
    [ ] Phase 3: Full-car "base-line" model CFD analysis.
    [ ] Phase 4: DRS (Drag Reduction System) mechanism and aero-elasticity tests.
